2. Implementation Tips & Gotchas
2.1 WAL & PRAGMAs
PRAGMA journal_mode=WAL; must be executed once per connection before any tables are created.
Include PRAGMA synchronous=NORMAL; for a good balance of durability vs. throughput.
Set busy_timeout early so SQLite will wait for locks rather than raising immediate errors.
2.2 Index Creation
Wrap each CREATE INDEX IF NOT EXISTS … in a migration script that also checks for existing indexes (SELECT name FROM sqlite_master WHERE type='index').
Consider composite indexes for frequent multi‑column filters, e.g., (carrier, processing_status) if those are often queried together.
2.3 Unique Constraint
The unique index on source_id assumes a deterministic identifier for each source file. If you ever ingest the same file from two different locations, ensure the identifier is truly global (hash of content + origin URL works well).
2.4 Retry Logic
Use requests.adapters.HTTPAdapter with a built‑in Retry strategy for cleaner code:
from urllib3.util.retry import Retry
from requests.adapters import HTTPAdapter
import requests

session = requests.Session()
retry = Retry(
    total=5,
    backoff_factor=2,
    status_forcelist=[429, 500, 502, 503, 504],
    method_whitelist=["GET", "POST"]
)
adapter = HTTPAdapter(max_retries=retry)
session.mount("http://", adapter)
session.mount("https://", adapter)

def fetch(url, **kw):
    return session.get(url, timeout=config.REQUEST_TIMEOUT, **kw)
2.5 Conditional Download
Store a small metadata row per file: {source_id, etag, sha256, last_seen}.
On each crawl, issue a HEAD request first; if ETag matches the stored value, skip the download entirely.
2.6 Structured Logging
Use Python’s logging module with a JsonFormatter. Example:
import logging, jsonlog

logger = logging.getLogger("pa_audit")
handler = logging.StreamHandler()
handler.setFormatter(jsonlog.JsonFormatter())
logger.addHandler(handler)
logger.setLevel(logging.INFO)
Include a run_id (UUID) in every log entry to correlate events across the pipeline.
2.7 Backup Automation
SQLite can be backed up safely with the backup API while the DB is open:
import shutil, datetime, os
def create_backup(src_path):
    ts = datetime.datetime.now().strftime("%Y%m%d_%H%M%S")
    dst = f"backups/pa_insurance_audit_{ts}.db"
    shutil.copyfile(src_path, dst)
    return dst
Schedule the backup at the very start of main.py; abort the run if the copy fails.
2.8 Job Lock & Concurrency
Create a lock file containing the PID and start timestamp. On startup, check if the file exists and whether the PID is still alive (os.kill(pid, 0)).
Remove the lock in a finally: block or via a signal handler for SIGTERM/SIGINT.
2.9 Parallel OCR
SQLite writes are not thread‑safe without a connection per thread. Keep a single writer thread (or use a queue) that serializes DB inserts, while OCR workers run concurrently and return extracted data structures.
2.10 Alert Engine Extensibility
Model alerts as rows in an alerts table with a JSON payload column (details). This lets you add new rule types without schema changes.
Provide a simple rule registration API:
ALERT_RULES = []

def register_rule(fn):
    ALERT_RULES.append(fn)
    return fn
Each rule receives the processed document dict and can INSERT into alerts if conditions match.
