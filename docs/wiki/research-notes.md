# Research Notes

Use this page for concise notes that are ready for review but not yet part of
the formal report. Each note should include:

- the question being investigated;
- the primary source and date checked;
- the conclusion, with uncertainty stated plainly; and
- the next verification step, if one remains.

Long-form analysis belongs in the report documents. This page is an indexable
scratchpad for the project wiki, not a substitute for citations.
