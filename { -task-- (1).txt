# 3) Data acquisition plan (automated + manual fallback)

## 3.1 Crawling & API ingestion

Primary method: prefer official endpoints / downloads (PID filings page and product-rate filing pages). Fallback: structured scraping of HTML pages and attachments (PDFs, XLS, CSV). Respect robots.txt and rate limits. ([Pennsylvania Government][1])
Example resilient fetcher (Python, synchronous snippet — adapt for async aiohttp if you need scale):

import requests
from bs4 import BeautifulSoup
from urllib.parse import urljoin
import hashlib
import os
import time

BASE = "https://www.pa.gov/agencies/insurance/"

def fetch_page(url):
    r = requests.get(url, timeout=20)
    r.raise_for_status()
    return r.text

def save_binary(url, out_dir="downloads"):
    r = requests.get(url, stream=True, timeout=30)
    r.raise_for_status()
    os.makedirs(out_dir, exist_ok=True)
    fname = os.path.join(out_dir, hashlib.sha256(url.encode()).hexdigest()[:12] + "_" + os.path.basename(url))
    with open(fname, "wb") as f:
        for chunk in r.iter_content(8192):
            f.write(chunk)
    return fname

def crawl_rate_filings():
    html = fetch_page(urljoin(BASE, "posted-filings-reports-company-orders/product-and-rate-filings/aca-health-rate-filings"))
    soup = BeautifulSoup(html, "html.parser")
    # find links to PDFs and save
    for a in soup.select("a[href$='.pdf'], a[href$='.xlsx'], a[href$='.xls']"):
        save_binary(urljoin(BASE, a['href']))
        time.sleep(1)  # polite
Record provenance (source URL, fetch timestamp, content hash) for every artifact.

# 4) Document processing pipeline (OCR → parsing → structured extraction)

## 4.1 Recommended stack

**PDFs:** pdfplumber (structured text extraction), fallback to PyMuPDF or PyPDF2 if needed.
**Scanned pages / images:** pytesseract via pillow after preprocessing (deskew, binarize).
**Tables:** camelot or tabula-py for table extraction from PDFs.
**NLP / clause extraction:** Hugging Face transformer models or spaCy for named-entity extraction (carrier, CPT, provider, amounts, policy numbers), plus rule-based regexes for common key-value pairs (claim IDs, patient names, dates).
**Language model / classification:** small classifier pipelines for “possible overcharge”, “denial type: medical necessity / preauth missing / admin error”.
## 4.2 Robust OCR snippet (preprocessing + OCR):

from PIL import Image, ImageOps, ImageFilter
import pytesseract

def preprocess_image(path):
    img = Image.open(path)
    img = ImageOps.grayscale(img)
    img = img.filter(ImageFilter.MedianFilter(3))
    img = ImageOps.autocontrast(img)
    return img

def ocr_image(path):
    img = preprocess_image(path)
    text = pytesseract.image_to_string(img, lang="eng", config="--psm 1")
    return text
## 4.3 Extraction heuristics

Build a small rule engine to extract these canonical fields: policy_number, group_number, member_name, claim_id, service_date, billed_amount, allowed_amount, paid_amount, provider_npi, diagnosis_codes, procedure_codes (CPT).
For ambiguous extractions, store both raw text and extraction confidence.

# 5) Data model / storage (audit-grade)

Use SQLite (or Cloudflare D1) with strict provenance and indexing. Example simplified schema (DDL):

CREATE TABLE sources (
  id TEXT PRIMARY KEY,          -- e.g., sha256(url)
  source_url TEXT,
  fetched_at TEXT,
  file_path TEXT,
  file_hash TEXT,
  mime TEXT
);

CREATE TABLE documents (
  id TEXT PRIMARY KEY,          -- uuid
  source_id TEXT REFERENCES sources(id),
  doc_type TEXT,                -- 'policy','eob','filing','notice','complaint'
  carrier TEXT,
  policy_number TEXT,
  member_name TEXT,
  date_received TEXT,
  text TEXT,                    -- full extracted text
  metadata JSON,                -- extraction keys
  created_at TEXT DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_documents_carrier ON documents(carrier);
CREATE INDEX idx_documents_policy ON documents(policy_number);
Always store raw files + extracted text + JSON metadata. Keep text search-friendly fields indexed.
