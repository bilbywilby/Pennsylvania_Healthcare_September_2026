## 2. Statutory & Regulatory Oversight Framework

Forensic auditing in Pennsylvania requires cross-referencing federal mandates with Commonwealth-specific consumer protection statutes.

```
+-----------------------------------+
| Federal & PA Regulatory Stack |
+-----------------------------------+
|
+---------------------------+---------------------------+
| |
[Federal Protections] [PA State Protections]
• No Surprises Act (NSA) • Pa. Act 252 (2023)
- QPA Calculation - Point-of-Service Status
- Independent Dispute Res. (IDR) • PA SB 1071 / Act 39 (2024)
• ERISA § 502 Appeals - $1,500 Outpatient Deductible Cap
• ACA Preventive Mandate - ≤20% Coinsurance Ceiling
• 28 Pa. Code § 9.725
- In-Network Hold Harmless
```

### Key Pennsylvania Legislative Overrides

1. **Pa. Act 252 (2023) — Point-of-Service Disclosure:**
Insurers and facilities must provide clear written or electronic disclosure of provider network status at the point of service. Failure to provide this disclosure creates an immediate defense against balance bills.
2. **PA SB 1071 / Act 39 (2024) — Cost-Sharing Caps:**
- **Outpatient Services Deductible Cap:** Caps individual deductibles for outpatient services at **$1,500**.
- **Coinsurance Ceilings:** Limits coinsurance to **$\le 20\%$** after deductible for outpatient surgical services.
- **Biomarker Mandates:** Eliminates prohibitive cost-sharing for medically indicated biomarker testing.
3. **28 Pa. Code § 9.725 — Hold-Harmless Provisions:**
Protects insured enrollees from paying in-network providers any amounts in excess of the negotiated contract rate, prohibiting auxiliary facility fee add-ons for covered benefits.
4. **PA SB 268 — Co-pay Accumulator Protections:**
Requires health plans to count direct manufacturer co-pay assistance coupons toward the enrollee's annual deductible and out-of-pocket maximum calculations.

## 4. Algorithmic Forensic Audit Engine

The internal claim variance classification uses a piecewise model comparing billed charges against regional Fair Market Value (FMV) benchmarks (derived from Medicare base rates multiplied by regional contract factors $1.15\times - 2.50\times$).

### Internal Variance Classification Formula

$$\text{Variance (\%)} = \left( \frac{\text{Billed Amount} - \text{FMV Target}}{\text{FMV Target}} \right) \times 100$$

* **Tier 1: Minor Discrepancy ($15.0\% \le \text{Variance} < 40.0\%$):** Automated line-item verification and facility charge-master audit.
* **Tier 2: Critical Variance ($\text{Variance} \ge 40.0\%$):** Immediate claim payment hold; mandatory secondary clinical review and formal billing inquiry.

> **Methodological Note:** These percentage variance tiers are internal risk-triage tools and do not modify statutory Qualifying Payment Amount (QPA) rules under federal NSA dispute resolution.

### Python Audit Logic Core

```python
"""
Forensic Medical Bill Audit Engine for Pennsylvania Health Plans (2026).
"""

from typing import Dict, Any

def audit_bill(
eob: Dict[str, Any],
sbc: Dict[str, Any],
eoc: Dict[str, Any],
ytd: Dict[str, Any],
state_rules: Dict[str, Any]
) -> Dict[str, Any]:
"""
Evaluates a single Explanation of Benefits (EOB) line-item against
contractual, statutory, and actuarial parameters.
"""
flags = []
recommended_action = "APPROVE_AND_PAY"

billed = float(eob.get("billed_amount", 0.0))
fmv_target = float(eob.get("fmv_target", 1.0))

# 1. Internal FMV Variance Calculation
variance = ((billed - fmv_target) / fmv_target) * 100.0
if variance >= 40.0:
flags.append("CRITICAL_OVERCHARGE_TIER_2")
recommended_action = "ITEMIZED_BILL_REQUEST"
elif variance >= 15.0:
flags.append("ELEVATED_VARIANCE_TIER_1")
recommended_action = "ITEMIZED_BILL_REQUEST"

# 2. Upcoding / Complexity Check
cpt_complexity = int(eob.get("cpt_complexity_score", 1))
narrative_score = int(eob.get("patient_narrative_score", 1))
if cpt_complexity > narrative_score + 1:
flags.append("POTENTIAL_UPCODING_DETECTED")
recommended_action = "CLINICAL_CHART_AUDIT"

# 3. PA Statutory Coinsurance Cap Check (PA SB 1071 / Act 39)
if eob.get("is_outpatient_surgical", False):
coinsurance_pct = float(eob.get("coinsurance_pct", 0.0))
if coinsurance_pct > 20.0:
flags.append("STATUTORY_VIOLATION_PA_SB1071_COINSURANCE_CAP")
recommended_action = "SUBMIT_PA_COMPLAINT"

# 4. No Surprises Act (NSA) Protection Check
facility_in_net = eob.get("facility_in_network", True)
provider_in_net = eob.get("provider_in_network", True)
if facility_in_net and not provider_in_net:
if eob.get("is_balance_billed", False):
flags.append("NSA_BALANCE_BILLING_VIOLATION")
recommended_action = "SUBMIT_NSA_APPEAL"

# 5. Out-of-Pocket Maximum Check
oop_spend = float(ytd.get("oop_spend", 0.0))
oop_max = float(sbc.get("oop_max", 9200.0))
if oop_spend >= oop_max and float(eob.get("patient_responsibility", 0.0)) > 0:
flags.append("POST_OOP_MAX_PATIENT_CHARGE")
recommended_action = "REISSUE_EOB_ZERO_BALANCE"

return {
"claim_id": eob.get("claim_id"),
"variance_pct": round(variance, 2),
"flags": flags,
"recommended_action": recommended_action
}
```

## 5. Verification-of-Benefits (VoB) Script & Checklist

When advocating for enrollees prior to or immediately following a medical service in Pennsylvania, patient advocates use the following 8-point verification protocol:

| # | Teleconference Verification Question | Statutory & Policy Rationale |
| :--- | :--- | :--- |
| **1** | *"Is the provider actively in-network for this specific plan network code?"* | Verifies network status; triggers Pa. Act 252 point-of-service disclosure requirements. |
| **2** | *"Is the procedure coded as preventive (e.g., CPT 99385–99387, 99201–99205 with wellness modifier)?"* | Mandates $100\%$ coverage with zero cost-sharing under the ACA and PA Department of Insurance guidelines. |
| **3** | *"Will the deductible apply, and is it subject to the $1,500 outpatient deductible cap?"* | Enforces PA SB 1071 limits on outpatient diagnostic and surgical deductibles. |
| **4** | *"What is the exact coinsurance percentage after deductible for this service type?"* | Enforces Commonwealth statutory cap ($\le 20\%$ for outpatient surgical services). |
| **5** | *"Does this facility charge a separate facility fee (Type T or UB-04 bill) for outpatient visits?"* | Identifies unbundled facility fees subject to 28 Pa. Code § 9.725 hold-harmless protection. |
| **6** | *"What is the member's current Year-to-Date progress toward the annual Out-of-Pocket maximum?"* | Ensures zero cost-share applies once the annual OOP ceiling is reached. |
| **7** | *"If an out-of-network provider treats me at an in-network facility, is protection under the NSA active?"* | Confirms federal No Surprises Act balance billing prohibition applies. |
| **8** | *"What exact CPT/HCPCS codes and modifiers will be submitted on the pre-authorization request?"* | Enables pre-service audit for modifier misuse, unbundling, or missing biomarker overrides. |

## 6. Relational Database Schema (PostgreSQL Specifications)

The backend infrastructure supports auditing, prior authorization tracking, and immutable event logging for the Layered Memory Protocol (LMP).

```sql
-- PostgreSQL Schema for Pennsylvania Health Insurance Audit Framework (2026)

CREATE EXTENSION IF NOT EXISTS "uuid-ossp";

-- 1. Immutable Event Store (Layered Memory Protocol)
CREATE TABLE events (
event_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
sha256_hash VARCHAR(64) NOT NULL UNIQUE,
event_type VARCHAR(64) NOT NULL,
source_system VARCHAR(64) NOT NULL,
payload JSONB NOT NULL,
recorded_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
wal_lsn PG_LSN,
version INT NOT NULL DEFAULT 1
);

-- 2. Rating Areas Lookup
CREATE TABLE rating_areas (
rating_area_id SMALLINT PRIMARY KEY,
primary_hub VARCHAR(128) NOT NULL,
description TEXT NOT NULL
);

-- 3. County Rating Area Map (67 PA Counties)
CREATE TABLE county_rating_map (
county_fips VARCHAR(5) PRIMARY KEY,
county_name VARCHAR(64) NOT NULL,
rating_area_id SMALLINT NOT NULL REFERENCES rating_areas(rating_area_id)
);

-- 4. Health Plan Carriers
CREATE TABLE carriers (
carrier_id SERIAL PRIMARY KEY,
carrier_name VARCHAR(128) NOT NULL UNIQUE,
market_share_2025 NUMERIC(5, 2),
created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 5. Rate Filings
CREATE TABLE rate_filings (
filing_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
carrier_id INT NOT NULL REFERENCES carriers(carrier_id),
rating_area_id SMALLINT NOT NULL REFERENCES rating_areas(rating_area_id),
approved_rate_change NUMERIC(5, 2) NOT NULL,
effective_date DATE NOT NULL,
event_ref UUID REFERENCES events(event_id)
);

-- 6. Prior Authorization Metrics (GLP-1 and Specialty Drugs)
CREATE TABLE policy_documents (
policy_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
carrier_id INT NOT NULL REFERENCES carriers(carrier_id),
drug_class VARCHAR(64) NOT NULL,
bmi_cutoff NUMERIC(4, 1),
therapy_months SMALLINT,
step_therapy BOOLEAN NOT NULL DEFAULT FALSE,
documentation_req TEXT,
event_ref UUID REFERENCES events(event_id)
);

-- 7. Materialized View: Carrier Prior Authorization Stringency Index
CREATE MATERIALIZED VIEW carrier_pa_index AS
SELECT
p.carrier_id,
c.carrier_name,
(
COALESCE(p.bmi_cutoff / 50.0, 0) * 35 +
COALESCE(p.therapy_months / 12.0, 0) * 30 +
(CASE WHEN p.step_therapy THEN 20 ELSE 0 END) +
(LEAST(LENGTH(p.documentation_req)::NUMERIC / 200.0, 1.0) * 15)
) AS pa_stringency_score
FROM policy_documents p
JOIN carriers c ON p.carrier_id = c.carrier_id;

-- Performance Indexing
CREATE INDEX idx_events_type ON events(event_type);
CREATE INDEX idx_rate_filings_ra ON rate_filings(rating_area_id);
CREATE INDEX idx_county_rating ON county_rating_map(rating_area_id);
```

]


def load_crosswalk(path: Path = CROSSWALK_PATH) -> Dict[str, Dict[str, Any]]:
    """Load and validate the county/FIPS/rating-area crosswalk generated by 02_crosswalk.py."""
    raw = json.loads(path.read_text())
    # Tolerate both {"counties": [...]} and bare-list shapes
    counties = raw["counties"] if isinstance(raw, dict) else raw

    fips_to_area: Dict[str, Dict[str, Any]] = {}
    seen_fips = set()
    for entry in counties:
        fips = str(entry["fips"]).zfill(5)
        if fips in seen_fips:
            raise ReconciliationError(f"Duplicate FIPS in crosswalk: {fips}")
        if not fips.startswith("42"):
            raise ReconciliationError(f"Non-PA FIPS in crosswalk: {fips}")
        seen_fips.add(fips)
        fips_to_area[fips] = {
            "county_name": entry["name"],
            "rating_area": int(entry["rating_area"]),
            "carriers": [],
            "weighted_rate_increase": 0.0,
        }

    if len(fips_to_area) != EXPECTED_COUNTIES:
        raise ReconciliationError(
            f"Crosswalk has {len(fips_to_area)} counties, expected {EXPECTED_COUNTIES}"
        )
    return fips_to_area


def build_county_rate_matrix() -> Dict[str, Any]:
    """Map each county FIPS to active carriers with market-share-weighted rate exposure."""
    fips_to_area = load_crosswalk()

    for filing in CARRIER_RATE_FILINGS:
        bad = set(filing["rating_areas"]) - VALID_RATING_AREAS
        if bad:
            raise ReconciliationError(f"{filing['carrier']}: invalid rating areas {sorted(bad)}")
        for area_id in filing["rating_areas"]:
            for data in fips_to_area.values():
                if data["rating_area"] == area_id:
                    data["carriers"].append({
                        "carrier": filing["carrier"],
                        "approved_rate_change": filing["rate_change"],
                        "market_share": filing["share"],
                    })

    for data in fips_to_area.values():
        if data["carriers"]:
            total_share = sum(c["market_share"] for c in data["carriers"])
            if total_share <= 0:
                raise ReconciliationError("Zero/negative total market share in a county")
            data["weighted_rate_increase"] = round(
                sum(c["approved_rate_change"] * c["market_share"] for c in data["carriers"])
                / total_share, 2,
            )
        else:
            data["weighted_rate_increase"] = None  # county with no active carrier → audit flag

    return fips_to_area

def normalize_crosswalk(raw: Any) -> List[Dict[str, Any]]:
    """
    Normalize all known crosswalk shapes into a canonical list of
    {"fips": str, "name": str, "rating_area": int} entries.

    Accepted shapes:
      A. {"counties": [{fips, name, rating_area}, ...]}   (02_crosswalk.py output)
      B. [{fips, name, rating_area}, ...]                  (bare list)
      C. {"<area_id>": [{fips, county}, ...], ...}         (rating-area-keyed,
                                                            carrier-ingestor style)
    """
