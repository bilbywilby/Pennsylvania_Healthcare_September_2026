# 2. Database Hardening Improvements (Critical)

## 2.1 Enable WAL Mode

In `DatabaseManager.init_schema()`:

```sql
PRAGMA journal_mode=WAL;
PRAGMA synchronous=NORMAL;
PRAGMA foreign_keys=ON;
PRAGMA temp_store=MEMORY;
PRAGMA busy_timeout=5000;
```

### Benefits

* Prevents write-lock failures
* Allows concurrent reads during processing
* Improves crash recovery

---

## 2.2 Add Critical Indexes (Performance Scaling)

Add migration:

```sql
CREATE INDEX IF NOT EXISTS idx_documents_doc_type ON documents(doc_type);
CREATE INDEX IF NOT EXISTS idx_documents_carrier ON documents(carrier);
CREATE INDEX IF NOT EXISTS idx_documents_policy ON documents(policy_number);
CREATE INDEX IF NOT EXISTS idx_documents_status ON documents(processing_status);

CREATE INDEX IF NOT EXISTS idx_extractions_field ON extractions(field_name);
CREATE INDEX IF NOT EXISTS idx_processing_job ON processing_log(job_id);
CREATE INDEX IF NOT EXISTS idx_alerts_severity ON alerts(severity);
```

Prevents query degradation at scale.

---

## 2.3 Add Unique Constraint for Idempotency

Prevent duplicate document insertion:

```sql
CREATE UNIQUE INDEX IF NOT EXISTS idx_documents_source_unique
ON documents(source_id);
```

Avoids re-processing identical source files.

# 3. Crawler Resilience Improvements

## 3.1 Retry with Exponential Backoff

Wrap all HTTP calls:

```python
def fetch_with_retry(url, retries=5):
    for attempt in range(retries):
        try:
            response = requests.get(url, timeout=config.REQUEST_TIMEOUT)
            response.raise_for_status()
            return response
        except requests.RequestException:
            sleep = 2 ** attempt
            time.sleep(sleep)
    raise Exception(f"Failed after {retries} attempts")
```

---

## 3.2 Conditional Downloading (ETag / Hash Check)

Before downloading:

* Compare file hash in DB
* Skip if unchanged

Prevents redundant OCR and processing.

## 3.3 User-Agent Hardening

Set explicit UA header to avoid PID blocking:

```python
headers = {
    "User-Agent": "PA-Insurance-Audit-Bot/1.0 (Compliance Monitoring)"
}
```

# 4. Document Processing Improvements

## 4.1 OCR Failure Fallback Strategy

If:

* `pdfplumber` extracts < 500 chars
* OR confidence < threshold

Then:

* Convert PDF pages to images
* Run OCR page-by-page

Improves coverage for scanned filings.

---

## 4.2 Confidence Normalization

Standardize confidence score:

```
confidence =
  0.5 * field_extraction_score +
  0.3 * text_density_score +
  0.2 * regex_validation_score
```

More stable scoring across document types.

---

## 4.3 Timeout Guard for OCR

Wrap OCR with:

```python
signal.alarm(30)
```

Prevents hanging on malformed PDFs.
